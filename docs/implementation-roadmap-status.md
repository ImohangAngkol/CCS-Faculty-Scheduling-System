- Actual routers, API schemas, services, page routes, empty page files, explicit “This page will be built next” placeholders and regression tests.

No single comprehensive original roadmap or Phase 3A audit artifact was found in the repository. No AGENTS.md was found. The initial broader user roadmap is useful context, but it does not establish a repository milestone for a feature that the repository never scheduled. Such features are separated into N rows. Source placeholders establish intent to build a page; they do not establish a detailed CRUD specification.

One R row counts as one reconstructed requirement group. Coupled acceptance details (e.g. dragging, moving and fixed duration) are stated in their rows rather than counted as arbitrary weighted percentages. This is **56 requirement groups found**, not a claim that the original request contained exactly 56 atomic bullets. N rows are excluded from this total. All totals are simple row counts; there is no completion percentage.

Documentation drift matters: README still describes resizing, while Phase 2 disables it. Older architecture/workflow documents enumerate six soft penalties; the inspected current scorer has eight. Later phase contracts, source and tests determine current behavior. These earlier descriptions are not instructions to restore old behavior.

Status definitions:

- **COMPLETE AND VERIFIED:** implemented within the stated scope, with a successful named test or documented prior verification. It does not certify production-sized performance or every untested edge case.
- **IMPLEMENTED BUT NOT FULLY TESTED:** useful implementation exists, but the stated end-to-end scope lacks sufficient evidence.
- **PARTIALLY IMPLEMENTED:** an important requested behavior is missing or a confirmed defect prevents the full requirement.
- **UI PLACEHOLDER ONLY:** route/page exists but does not implement the feature.
- **NOT IMPLEMENTED:** documented requirement has no working implementation.
- **BLOCKED:** a concrete prerequisite prevents work; no row is classified this way merely because it is future work.
- **NOT FOUND IN DOCUMENTED ROADMAP:** no detailed original repository commitment/milestone found. Its actual availability is described separately.

Priorities: P0 = data protection/access/correctness prerequisite; P1 = next operational capability or important reliability work; P2 = later usability/research/qualification.

Paths in tables: **B/** = `backend/`; **F/** = `frontend/src/`. Bare files following a directory-qualified entry are in that same directory. GA `/runs...`, `/status` and `fitness-analysis...` paths use the `/api/ga` prefix; chromosome `/upload`, `/best/analyze`, etc. use `/api/chromosomes`. Preference paths retain their actual `/preferences` prefix.
