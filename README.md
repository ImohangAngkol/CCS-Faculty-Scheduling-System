# CCS Faculty Scheduling System

A Genetic Algorithm-based Faculty Scheduling Decision-Support System for the College of Computer Studies (CCS), Mindanao State University – Iligan Institute of Technology (MSU-IIT).

## 📌 Project Overview

The CCS Faculty Scheduling System is a decision-support system designed to assist in generating faculty schedules while considering academic requirements, faculty workload, scheduling constraints, and faculty preferences.

The system uses a Genetic Algorithm to search for improved scheduling solutions and identify a suitable schedule based on defined constraints and fitness criteria.

## 🎯 Objectives

- Automate and improve the faculty scheduling process.
- Generate schedules while satisfying required scheduling constraints.
- Consider faculty workload and teaching preferences.
- Minimize scheduling conflicts.
- Provide a dashboard for viewing and evaluating generated schedules.
- Use the best-performing chromosome as the current scheduling baseline.

## 🧬 Genetic Algorithm

The Genetic Algorithm is designed to generate and evaluate possible faculty schedules.

The system considers factors such as:

- Faculty workload
- Subject assignments
- Faculty specialization
- Faculty preferences
- Schedule conflicts
- Room availability
- Time-slot availability
- Institutional workload requirements

The best chromosome generated by the algorithm is retained as the current baseline. If a newly generated chromosome performs better, it replaces the previous baseline.
